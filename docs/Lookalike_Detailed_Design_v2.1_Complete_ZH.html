1. 设计概述与原则

本文档为 Lookalike 详细设计定稿 v2.1：在 BRD 目标能力不变的前提下，采用「MVP → P1 → P2」分阶段落地，并与现有 FastAPI + LightGBM 仓库对齐。完整前端与外部系统集成属于 P2。

1.1 产品目标

Lookalike Audience & Lead Generation 是 Smart Sale CDP 中的 AI 扩客能力：基于产品 Project Model 的种子客群（Sample），对候选客群（Potential）计算 Similarity Score（0–1），输出可运营的 Lookalike 集合、特征重要性与 Dashboard，支持导出/Segment，并可跟踪转化。

1.2 设计原则

  1. 分数与阈值分离：创建 Process 不采集 Similarity Threshold；Generate 对 100% 有效候选打分；阈值仅用于 Dashboard / Export。
  2. 版本不可变：每次运行生成独立 Version，配置快照冻结。
  3. 训练与打分解耦：Offline 训练写入 Model Registry；Online Generate 只加载已部署模型。
  4. 时间泄漏零容忍：训练前强制 denylist 审计，命中即失败。
  5. 双模型独立：每产品 LightGBM（主）+ LR+WOE（可解释基线）。
  6. 冷启动排除：无交易/无 App 行为客户不进入 Lookalike 覆盖。
  7. 指标不作硬门禁：AUC/KS 为诊断；业务成功以 Lift / A/B 为准。

5. 特征工程流水线

flowchart LR A[抽取]-->B[同CIF剔除] B-->C[冷启动过滤] C-->D[缺失/同值/IV筛选] D-->E[高偏度P99截断] E-->F[时间泄漏审计] F-->G[LR用WOE / LGB用原始] G-->H[特征产物]

5.1 质量规则

规则阈值动作
缺失率> 95%剔除特征
同值率> 95%剔除特征
IV< 0.02剔除特征
偏度显著偏高P99 截断
缺失填补—数值中位数 / 类别众数

5.2 时间泄漏 denylist（强制失败）

  • 放款后字段：当前贷款余额、放款日
  • 触达后结果、他模型输出分（如 ResponsePropensity）
  • 纯标识：CIF、证件号
  • 候选池内恒定的 eligibility 字段
任一 denylist 字段残留 → 训练/准备任务失败并写审计，禁止“警告后继续”。

5.3 冷启动

Observation Window 内交易次数=0 且 App 活跃天数=0 → 计入 insufficient_data，不打分。身份无法映射 → unmapped。

5.4 Event Importance / RFM

对窗口内各 Event 计算 Recency / Frequency / Monetary。Dashboard 同时展示静态 Feature Importance 与 Event Importance。MVP 可用模型 gain 近似；P1 补齐 RFM 报表。

6. 模型训练设计（双产品双轨）

统一口径：每产品训练 LightGBM（primary） 与 LR+WOE（baseline）。推理默认 primary。XGBoost 仅作备选，不入一期。

6.1 样本语义

  • 正样本：已获批放款、逾期可控、满足观察期
  • 负样本：有机会但未转化的合格客群，不是“坏客户”
  • 排除：员工/测试/销户/身故/硬性不合格

11. 推理与打分流水线

  1. 加载已部署 primary 模型与 feature_list
  2. 候选身份映射；过滤 unmapped / cold-start / 硬性不合格
  3. Adapter → 清洗 → 批量 predict_proba 作为 Similarity Score
  4. 写入 scoring_result（key+score+rank）与 analysis_snapshot（直方图等）
  5. Dashboard / Export 按阈值过滤，不重打分

13. 安全、合规与公平性

  • P1：企业 SSO/OIDC；RBAC（Marketing / DS / Admin / Auditor）
  • 导出短时签名 URL；Audit Log 不可 UPDATE/DELETE
  • 公平性：按 gender / age_band / region 监控转化率差
  • 敏感特征默认不进入对外解释文案
  • 第三方数据按合同与最小化原则接入

14. 模型监控与重训

  • 月度 PSI；特征或分数 PSI > 0.25 → 告警，不自动盲切流量
  • 重训需人工 Approve；Canary：30% → 50% → 100%，可回滚
  • Registry 状态：training → validated → deployed → retired
